# course/ — 12+2 讲课程包（CC BY-SA 4.0）

> 教学定位见 ADR-001；2–3 人一组、每组一台 Otto 学生机，按模块认领。
> 期末验收：**3 分钟连续陪伴对话演示**（听得懂带口音的话、记得住上次聊的事、会用动作回应、有安全兜底）。

| 讲 | 主题 | 实验产出 |
|---|---|---|
| 1–2 | 项目全景 + 伦理红线 + Otto 组装 | 机器人动起来（舵机/动作库） |
| 3–4 | 语音链路（VAD/ASR/TTS，小智模式） | 能对话（端到端跑通） |
| 5–6 | 云端大脑（Agent 路由 + 记忆三层 + 健康语料整理） | 会记住你上次聊的事 |
| 7–8 | **动作语义层（跨本体抽象）**——同一句话在 Otto / Reachy 上不同表达 | 情感映射表 + 演示 |
| 9–10 | 多模态情感 + 安全风控（防诈骗/跌倒告警） | 情绪回应 + 告警闭环 |
| 11–12 | 场景包（老人→小学生切换）+ 集成演示 | 期末公开展示 |
| 13（扩展） | 大亮接入：双网关架构 + 底盘 Mock + 上位机尽调案例 | chassis-gateway 联调 |
| 14（扩展） | 部署与成本：实验室边缘 vs 产品化、未成年人合规差异（讨论课） | 方案辩论 |

## 工程规范（第 1 讲就教）

- fork 纪律：`suiyue/` overlay、`[PATCH]` 前缀、NOTICE 维护；
- 许可证红线：进仓库的代码先查 LICENSE（小歪 GPL-3.0 出局的案例）；
- 用量看板：API 成本每组可视化（借鉴小歪设计）。
