# ADR-008 记忆三层与画像标签

日期：2026-09-06 ｜ 状态：已接受

## 记忆三层
| 层 | 存储 | 内容 | 读写规则 |
|---|---|---|---|
| 短期 | Redis | 当前会话最近 10 轮 / ~2000 token | 滑动窗口 |
| 长期 | 向量库 | LLM 每轮抽取的"值得记住的事实" | 语义相似度 × 时间衰减，召回 top-5；**相似度 >0.92 不新增，只累加 mention_count** |
| 结构化 | MySQL | 老人画像标签 | 见下 |

多租户：`device_id + group_id` 双键隔离（每个学生组独立画像）。

## 画像标签三档（expires_at 必填）
| 档 | 例子 | 生命周期 |
|---|---|---|
| 永久 | 籍贯、曾从事职业、子女姓名 | 永不过期 |
| 半永久 | 高血压、腿脚不便 | **二次确认后才落库** |
| 时效 | 今日未出门、最近失眠 | TTL 24h–7d 自动过期 |

## 防幻觉纪律
- LLM 只允许抽取**预定义白名单字段表**中的值，禁止自由生成标签；
- 低置信度不落库，转为**反问确认**（"您刚提到腿疼，是最近才开始的吗？"）——把不确定变成一次自然关怀。

## 重复叙事（老人讲同一件事第 8 遍）
检测到高相似记忆命中 → 回复策略 = 接话 + 延展新角度。这是核心论文点之一。
