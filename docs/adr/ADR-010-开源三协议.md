# ADR-010 开源三协议

日期：2026-09-06 ｜ 状态：已接受

| 资产 | 协议 | 文件 |
|---|---|---|
| 代码（brain / 固件 / 客户端 / 网关 / App） | Apache-2.0 | `LICENSE` |
| 硬件（结构件 / 电路 / BOM） | CERN-OHL-S 2.0 | `hardware/LICENSE-CERN-OHL-S` |
| 课程包 / 文档 / 验收脚本 | CC BY-SA 4.0 | 各目录内注明 |

## 理由
- Apache-2.0：与三个 MIT 上游兼容（见 NOTICE），含专利授权条款，对将来产品化最友好；
- CERN-OHL-S：硬件界的"源码可得"标准协议， Otto DIY 上游即此系；
- CC BY-SA：课程包允许再分发与改编、要求同协议共享，防止被商业机构拿走闭源。

## 纪律
- 任何进入仓库的第三方代码，先查 LICENSE 再动手（本项目的转折点之一就是小歪因 GPL-3.0 出局）；
- `NOTICE` 文件随依赖变化同步更新。
