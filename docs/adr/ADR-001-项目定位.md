# ADR-001 项目定位：教学载体优先

日期：2026-09-06 ｜ 状态：已接受

## 背景
项目同时具备科研（论文）、教学（工作室制课程）、产品（商业闭环）三种可能驱动力，资源分配逻辑互相冲突。

## 决策
**教学载体优先，可能的话形成真实产品。** 科研产出（多模态情感、跨本体中间件、重复叙事检测）作为教学过程的衍生物；产品化作为远期愿景，不设近期 KPI。大亮接入后，"真实产品"的落地路径更新为 B 端（养老驿站/社区）移动服务平台。

## 后果
- 选型以"学生可上手、可拆解、可复现"为第一判据（如 Linux SBC + Python 优先于 ESP-IDF）；
- 单台预算分两档：Reachy Mini 展示机 ≤¥5000（1–2 台），Otto 学生机人均 ¥500–800；
- 验收以"可演示的陪伴对话"为准，不以论文/营收为准。
