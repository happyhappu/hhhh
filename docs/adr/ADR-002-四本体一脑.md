# ADR-002 四条本体线，一个软件大脑

> 文件名已由 `ADR-002-三本体一脑.md` 更名为 `ADR-002-四本体一脑.md`（2026-09-22，与标题对齐）。
> 历史：2026-09-07 扩展至三本体；2026-09-11 新增 Pepper 本体升级为四本体。

日期：2026-09-06（2026-09-07 扩展至三本体；2026-09-11 扩展至四本体） ｜ 状态：已接受

## 决策
Otto（桌面双足，ESP32）、Reachy Mini（桌面表达，树莓派5）、大亮（1.56m 移动人形，Android+EGO底盘）、Pepper（1.2m 三轮人形，NAOqi OS）四条本体线**共用一个云端软件大脑**；端侧 OS 透明（RTOS / Linux / Android / NAOqi 皆可），云端只认协议不认 OS。

## 关键事实
- Otto：小智生态已内置 `main/boards/otto-robot/` 板级支持（28 种动作、MCP 工具、WS 控制服务器），动作能力"白送"；
- Reachy Mini：表达力最强（6-DOF 头+天线+LED 眼+4 麦+扬声器），加 4.3–5" HDMI 胸前内容屏，LED 眼睛管情感、屏管内容；
- 大亮：底盘 L4 开放（易行 EGO），上位机接口待尽调（ADR-009）；
- Pepper：SoftBank NAOqi 人形，20 自由度 + 10.1" 平板 + 4 麦 + RGB-D 深度；自带 NAOqi 中间件（Python SDK `qi`，连 `tcp://<ip>:9559`）；机载算力弱（x86 嵌入式级），**只作纯客户端**，不本地跑 LLM，不增加 4090 显存预算（ADR-011）。

## 后果
- "统一大脑"成立的代价是必须有跨本体抽象层（ADR-004），否则四套端栈 = 四个项目；
- 采购：Reachy Mini Wireless（$499，含树莓派5）+ Otto 双机（成品黄金参照机 + 散件教师机）+ 大亮（B 端演示机）+ Pepper（教学/展示级移动人形）；
- Pepper 接入范式与大亮一致：一个 body-driver 网关（`pepper/`，NAOqi 桥）+ 能力注册表条目（`pepper_v1.yaml`）+ 场景包（`pepper_cn_v1/`），云端零改动（见 `pepper/README.md`）。
