# ADR-006 端侧栈：Linux SBC + Python 为主线，Otto 过渡期用小智固件

日期：2026-09-06 ｜ 状态：已接受

## 决策
- 目标架构：三层（ESP32 下位机管实时舵机 + Linux SBC 上位机管屏/音频/相机/云端链路）；
- **MVP 阶段：统一 Linux SBC + Python**（香橙派 Zero 2W ¥89 起 / Reachy 用自带树莓派 5）；
- Otto 线第一学期直接跑小智 ESP32 固件（一天出正反馈），第二学期做"跨本体统一"重构——本身就是第 7–8 讲的实验内容。

## 澄清过的误区
ESP32 ≠ 小电脑：无 MMU、屏上限 2.8" SPI、无视频流，PRD 的 5–7 寸大字 UI 与视频通话在 ESP32 上物理不可实现。ESP32 在本架构中的定位是**语音链路 + 下位机**，不是主控。

## 端侧软件栈（标准配置）
本地 Web UI（FastAPI + Chromium kiosk 全屏）+ sounddevice + silero-vad + Opus + WebSocket。端侧零 AI 推理（不要 NPU），视觉仅在交互触发时抽帧上云、不落盘。
