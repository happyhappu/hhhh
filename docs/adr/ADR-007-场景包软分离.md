# ADR-007 场景包软分离：persona / Agent 集 / 安全策略三层可插拔

日期：2026-09-06 ｜ 状态：已接受

## 决策
场景切换 = 换目录。结构：

```
brain/packs/<scene>/
├── persona.yaml      # 名字/人称/语气/音色/语速 + emotion→intensity 动作曲线
├── agents/           # system_prompt + tools + knowledge_base + trigger_examples
├── safety.yaml       # 敏感词/拒答/免责声明/紧急联系人/未成年人开关
├── ui/               # （可选）该场景的大屏 Web 模板
├── mobility.yaml     # （可选，大亮等移动本体）巡游点位/geofence
└── physical_caps.yaml # （可选）物理动作能力声明
```

## 老人场景（elder_cn_v1）与小学生场景（kids_v1）的关系
- **本期**：kids_v1 只做插槽 + 一个 PoC Agent（作业陪伴/十万个为什么），验证切换机制；
- **红线**：未成年人合规（内容审核/防沉迷/监护人同意）与老人场景完全不同，**绝不复用 safety 配置**，产品化阶段独立立项；
- 本体硬件统一迭代，不做场景分化硬件。

## 适老化关键规则（写进 persona）
重复叙事检测到时**接话延展新角度，绝不提示"您讲过了"**。
