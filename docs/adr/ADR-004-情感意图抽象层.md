# ADR-004 动作语义抽象：emotion + intensity（+可选原语），端侧映射

日期：2026-09-06（大亮接入后升级） ｜ 状态：已接受

## 决策
云端只下发**情感意图**：`{emotion, intensity, [action_primitive], [params]}`（契约见 `docs/MCP-CONTRACT.md`）。端侧查能力注册表（`brain/capabilities/`）+ 本地编排器，把意图翻译成本体支持的原子动作。

## 例子
同一句"孙子考上大学了，真高兴！"：
- Otto（happy, 0.7）→ 摇摆 + 挥手；
- Reachy Mini → 头上扬 + 天线摆 + LED 眯眼；
- 大亮 → 头部/表情屏响应 + （可选）approach 走近。

## 大亮引入的升级
移动维度使纯 `emotion` 不够表达"走近再说"，故扩展可选 `action_primitive + params`（navigate/patrol/approach...），由端侧（chassis-gateway）解释执行；云端编排器可做**复合编排**（emote ∥ navigate）。

## 安全规则
- 端侧对原语有权忽略（安全优先）；不认识的原语静默降级 neutral；
- Otto 保守动作子集 = 点头/摇头/摇摆/挥手/鞠躬/害羞；跳跃/太空步仅展示模式。
- `softScram` 急停任何 Agent 无条件可调。

## 论文点
这层"跨本体情感-动作中间件"是本项目的核心架构贡献。
