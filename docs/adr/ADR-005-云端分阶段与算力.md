# ADR-005 云端分阶段：先跑通，再自建

日期：2026-09-06 ｜ 状态：已接受

## 决策
- **第一学期**：不自建 ASR/LLM/TTS，用小智模式跑通端到端，让学生第一周就看到"能对话的机器人"；
- **第二学期**：拆成自建轻量云端——保留网关/会话中枢/Agent 三层概念，重写实现（原产品级代码本科生读不动）；
- LLM 路由：第一学期单 8B–14B；第二学期双模型路由（8B 管寒暄指令，高价值模型管情感/健康/安全）。
  > **2026-09-07 修订（ADR-011）**：全离线场景下 24GB 单卡放不下 30B（Q4 约 17–18GB，与 ASR+TTS 同卡必 OOM）。高价值档位本期降为 **14B Q4（约 9GB）**；30B 需新增第二张卡或迁至 DGX Spark 独立节点。以 ADR-011 为准。

## 算力决策（2026-09-06/07）
- 并发按"同时活跃 8–10 路"规划（非 30 路注册量）；
- 吞吐主力 = 现有 4090；**DGX Spark 不做并发服务器**（带宽 273GB/s 仅为 4090 的 1/4，8B 慢 3–6 倍），定位大模型节点 + LoRA 微调工作站；二选一先买 4090 级；
- AGX Orin = 产品化现场边缘节点（养老驿站低功耗形态），非本期采购；
- 网络：机器人一律走 5GHz 或专用 AP（2.4GHz 三信道挤爆）。
