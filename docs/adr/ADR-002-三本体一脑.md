# ADR-002 三条本体线，一个软件大脑

日期：2026-09-06（2026-09-07 扩展至三本体） ｜ 状态：已接受

## 决策
Otto（桌面双足，ESP32）、Reachy Mini（桌面表达，树莓派5）、大亮（1.56m 移动人形，Android+EGO底盘）三条本体线**共用一个云端软件大脑**；端侧 OS 透明（RTOS / Linux / Android 皆可），云端只认协议不认 OS。

## 关键事实
- Otto：小智生态已内置 `main/boards/otto-robot/` 板级支持（28 种动作、MCP 工具、WS 控制服务器），动作能力"白送"；
- Reachy Mini：表达力最强（6-DOF 头+天线+LED 眼+4 麦+扬声器），加 4.3–5" HDMI 胸前内容屏，LED 眼睛管情感、屏管内容；
- 大亮：底盘 L4 开放（易行 EGO），上位机接口待尽调（ADR-009）。

## 后果
- "统一大脑"成立的代价是必须有跨本体抽象层（ADR-004），否则三套端栈 = 三个项目；
- 采购：Reachy Mini Wireless（$499，含树莓派5）+ Otto 双机（成品黄金参照机 + 散件教师机）。
