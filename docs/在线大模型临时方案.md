# 4090 · 先用在线大模型 / 后切本地（临时方案配置指南）

> **适用**：初步联调阶段**暂不在4090 部署本地大模型**，直接调云端 API；
> 调试通过后再切回本地 Ollama（ADR-011 全离线基线）。
>
> **决策日期**：2026-10-12（用户）｜ **这是一次明确的临时偏离**，见§0 风险声明。
> 依据：`xiaozhi-esp32-server` **v0.9.7** `config.yaml` **真实行号**（逐行核对过）。

---

## 0. 先说清楚风险（重要）

**这个方案会让系统联网**，因此：

| 维度 | 影响 |
|---|---|
| **ADR-011 基线** | ⚠️ **暂时失效**。ADR-011 决策 1 要求"所有 AI 模块强制本地后端"，本次决策明确偏离 |
| **隐私** | 老人语音可能经云端 ASR/LLM/TTS 回传（**取决于你选哪些**，见 §2） |
| **成本** | API 按量计费 |
| **断网测试** | ❌ **联调期做不了** —— 断网后 LLM 直接不可用，无法验证 ADR-011 决策 5 三级降级 |
| **回切成本** | 🟢 **低**。只是改 2 行配置（§5），无代码改动、无数据迁移 |

>✅ **可以做的原因**：联调期的目的是验证「**链路通不通**」（WS / overlay / MCP / 情绪契约），
> 这些与 LLM 在哪跑**无关**。先用在线 API 跳过最麻烦的本地部署（驱动/权重/量化/OOM），
> 是合理的推进顺序。
>
> ⚠️ **但必须在项目里留痕**（见 §6），否则后面容易误判"已经全离线了"。

## 1. 核心改动：只改 `selected_module` 的 2 行

编辑 `/opt/xiaozhi-esp32-server/main/xiaozhi-server/config.yaml`：

```yaml
# L239 · LLM：默认 ChatGLMLLM（智谱 glm-4-flash，免费额度）
#        → ★只需填 api_key，type/url/model_name 都是现成的
LLM: ChatGLMLLM

# L243 · TTS：默认 EdgeTTS（微软，联网）→ ★保持不变即可，本就用在线
TTS: EdgeTTS
```

> 💡 **好消息**：`config.yaml` 的**默认值本来就是在线 API**
> （L239 `ChatGLMLLM` + L243 `EdgeTTS`）。
> 所以**在线方案几乎不用改结构**，只要**填 api_key**。
> 反而切回本地时才是"改结构"（换 provider 名）。

## 2. 填 api_key（v0.9.7 已内置的在线 provider）

### 2.1 LLM —— 5 个在线选项

| provider | 行号 | model_name（默认） | url / base_url | 备注 |
|---|---|---|---|---|
| **`ChatGLMLLM`** | L656 | `glm-4-flash` | `https://open.bigmodel.cn/api/paas/v4/` | ✅ **推荐**：免费额度，且**明确支持 function_call**（见 L250 注释） |
| `DoubaoLLM` | L639 | `doubao-seed-2-0-lite-260215` | `https://ark.cn-beijing.volces.com/api/v3` | 免费 50 万 token（见 L644 注释）；**上游推荐稳定方案**（L250） |
| `AliLLM` | L616 | `qwen-flash` | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 阿里百炼；**附带 temperature/max_tokens/top_p 等参数**（L623-626） |
| `DeepSeekLLM` | L649 | `deepseek-v4-flash` | `https://api.deepseek.com` | 注意默认 model 名的 `-flash` 后缀，**申请时确认可用型号** |
| `GeminiLLM` | L680 | — | Google | 国内需代理 |

**所有 OpenAI 兼容的服务（DeepSeek / 阿里 / 智谱 / 月之暗面…）都能接**
—— 上游统一用 `type: openai`，只要服务商的 `base_url` + `model_name` 对得上。

**最小改动示例**（用 ChatGLMLLM）：
```yaml
# L662-663
url: https://open.bigmodel.cn/api/paas/v4/
api_key: 你的真实key
```

### 2.2 TTS —— 保持 EdgeTTS 即可

```yaml
# L772-776 · EdgeTTS（微软，免费、无需 key）
EdgeTTS:
  type: edge
  voice: zh-CN-XiaoxiaoNeural
  output_dir: tmp/
```

> 🔴 **老人适配提醒**：`XiaoxiaoNeural` 是**年轻女声**。
> ADR-011 要求"老人温和女声"。联调期先用它跑通链路可以，
> 但**正式演示前必须换**（换在线 TTS 或切本地 GPT-SoVITS 克隆音色）。
>
> 在线 TTS 想换音色可直接改 `voice:`；上线的备选见
> `TTS.AliyunTTS`(L1000) / `TencentTTS`(L1044) / `DoubaoTTS`(L778)。

### 2.3 ASR —— 建议**仍用本地**（FunASR）

```yaml
# L237 · 保持 FunASR（本地模型，不联网）
ASR: FunASR
```

> 💡 **建议 ASR 保持本地**：老人语音是**最敏感的隐私数据**，能不出网就不出网。
> FunASR SenseVoiceSmall 是本地模型，只需下载一次（`models/SenseVoiceSmall`）。
>
> 若联调期想连ASR 也省掉，上游另有 `DoubaoASR`(L395) / `TencentASR`(L450) /
> `AliyunASR`(L458) 等在线选项 —— 但**不推荐**，且老人场景 ASR 准确率很关键。

### 2.4 VAD —— 必须本地
```yaml
VAD: SileroVAD     # L235，本地模型
```

## 3. 必须同时处理的两处联动（否则会出问题）

### 3.1 🔴 Intent 的 `function_call` 依赖 LLM 能力

```yaml
# L251 · Intent 保持 function_call
Intent: function_call
```

- `function_call` **要求所选 LLM 支持工具调用**。
- ✅ `ChatGLMLLM`(L656)、`DoubaoLLM`(L639) 明确支持（上游 L250 注释：
  "默认免费的 ChatGLMLLM 就已经支持 function_call"）。
- ⚠️ 若你选了**不支持 function_call 的模型**（如某些纯补全模型），
  MCP 工具（`self.suiyue.emote` 等）**不会被调用**，
  表现为"Pepper 会说话但不动"。

### 3.2 🔴 联网插件会一起被调用（花钱 + 出网）

```yaml
# L280-L290 · functions 列表
functions:
  - change_role
  - web_search                  # 🔴 联网搜索，会真的调公网
  - get_weather                 # 🔴 走公网 API
  - get_news_from_newsnow       # 🔴 走公网 API
  - play_music                  # 本地
```

**联调期建议先注释掉 3 个联网项**（避免老人问天气时真去调公网、也避免误触）：

```yaml
functions:
  - change_role
#   - web_search
#   - get_weather
#   - get_news_from_newsnow
  - play_music
```

> ⚠️ **别把列表删空** —— L278 注释明确说：`handle_exit_intent`（退出识别）和
> `play_music`（音乐播放）是**server 自带的本地插件**，"请勿重复加载"。
> `change_role`(L281) 同理。保留即可，这几个都不联网。
>
> 💡 如果想给老人做"天气问答"的**离线兜底话术**，后续可在场景包
> （`brain/packs/`）里加降级prompt，而不是依赖公网 API。

> 📌 **L278 的准确说法**：上游注释写的是 `handle_exit_intent`（退出识别）与
> `play_music`（音乐播放）"系统默认已记载，请勿重复加载"；
> `change_role`(L281) 是列表里显式加载的。三者均**不联网**。

## 8. 排障

| 现象 | 原因 | 处置 |
|---|---|---|
| LLM 无响应 / 反复重连 | api_key 没填或填错 | 看日志里的 401/403 |
| **Pepper 会说话但不动** | 🔴 LLM 不支持 `function_call` → MCP 工具没被调用 | 换 `ChatGLMLLM` / `DoubaoLLM` |
| LLM 报"找不到模型" | model_name 写错 | 对照服务商控制台的实际模型名 |
| 401/403 | key 过期 / 没开通服务 | 智谱需注册；豆包需先开通服务（L642-645 注释） |
| 联网超时 | 服务器无外网 / 需代理 | 确认 4090 能出网；`http_proxy` 也要设全 |
| EdgeTTS 不出声 | 微软接口被墙 | 换 `AliyunTTS`(L1000) / `TencentTTS`(L1044) / 切本地 |
| 老人语音外传（隐私） | ASR 用了在线 | 保持 `FunASR` 本地（L237） |
