## Otto 学生机（¥500–800/台）

完整 BOM 与避坑见上级目录《岁悦-阶段0-采购清单与教师预研checklist-v1.md》。要点：

| 件 | 规格 | 避坑 |
|---|---|---|
| 主控 | ESP32-S3-WROOM-**N16R8** | 必须乐鑫官方模组，杂牌射频差 |
| 舵机 | SG90 9g 180° ×6 | **按 1.5–2 倍冗余采购**（塑料齿轮打齿即报废） |
| 电池 | 103450 2000mAh（PH2.0） | 备注线序红黑 1.25 |
| 麦克风 | ZTS6672（替代 ICS-43434） | 焊接不易坏 |
| 功放 | MAX98357A | **不要 BGA 封装** |
| LCD | 1.54" 240×240 | 勿选瀚彩玻璃胶铁一体 |
| 3D 件 | body/head/leg×2/foot×2 | **必须 v1.3**（2025-05-15 修订版） |

boot 按键立创无匹配，需淘宝 6mm 高度。

## Reachy Mini 展示机（≤¥5000/台，1–2 台）

- Wireless 版 $499（树莓派 5 + 4 麦 + 电池）；
- 加屏：4.3–5" HDMI（微雪 5" 800×480 ≈$34），走 HDMI 不走 DSI，树莓派 5 需 micro-HDMI 转接线。

## 大亮 Plan B 外挂交互头（¥600–1500，视尽调结果启用）

香橙派 Zero 2W（¥89）或 RK3588 SBC + USB 麦阵列（ReSpeaker 类 ¥150–300）+ 扬声器 +
5" HDMI 屏 + 摄像头 + 3D 打印支架；软件直接复用 `client-py` 栈。

## 网络与备件

- **5GHz AP 或实验室专用 AP 必采购**（2.4GHz 只有 3 个不重叠信道，30 台设备必挤爆）；
- 教师机纪律：Otto 一成品（黄金参照机，不拆不改）+ 一散件（亲手装）。
